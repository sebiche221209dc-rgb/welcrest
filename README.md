# Welcrest

Tienda online moderna para productos electrónicos, con enfoque en audífonos y powerbands.

## Descripción

Este proyecto es una base inicial para una tienda digital con estilo profesional, limpio y fácil de manejar. Está desarrollado en HTML, CSS y JavaScript para que puedas editarlos rápidamente sin depender de un framework pesado.

## Características

- Diseño responsivo y profesional
- Sección de hero moderna
- Catálogo de productos con categorías
- Carrillo de compras funcional
- Filtros por categoría
- Fácil de adaptar para más productos y pagos

## Estructura

- `index.html` – Estructura principal
- `styles.css` – Estilos visuales
- `script.js` – Datos de productos y lógica del carrito

## Cómo abrirlo localmente

Puedes abrir `index.html` directamente en tu navegador, o ejecutar este comando desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Y luego visita:

```bash
http://localhost:8000
```

## Siguiente paso recomendado

Para convertir esta base en una tienda real con pagos, puedes conectar:

- Stripe para pagos
- WhatsApp para ventas directas
- Firebase o Supabase para almacenamiento
- Vercel para desplegar en línea
